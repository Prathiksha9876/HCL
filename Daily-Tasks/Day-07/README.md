# Day 07 – Library Waitlist and Collections

 Overview
Practises Java collections for managing library-related data such as a waitlist.

 Concepts Practiced
- Java Collections Framework
- Lists and collection operations
- Organizing code in a package
- Managing a sequence of waiting entries

 Structure
```text
Day-07/
├── src/main/java/library/
└── out/   # Generated compiler output; do not commit
```

 Compile
From the `Day-07` directory:
```powershell
javac -d out src/main/java/library/*.java
```

Run the actual class containing `main`. For example:
```powershell
java -cp out library.Main
```
Replace `library.Main` with the actual main class name.

 Status
