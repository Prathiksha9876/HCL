 Day 03 – ATM Simulator

Overview
A Java/Maven exercise for practising a small ATM-style console application.

 Concepts Practiced
- Java project structure
- Maven build lifecycle
- Compiling and packaging a Java application

 Structure
```text
Day-03/
├── pom.xml
├── src/main/java/
└── target/   # Generated by Maven; do not commit
```

 Build
Run from the `Day-03` directory:
```powershell
mvn clean package
```

 Notes
Maven-generated files are stored in `target/`. This folder can be ignored by Git.

 Status
Maven project and build workflow practised.
