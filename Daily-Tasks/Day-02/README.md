Day 02 – Monthly Usage Analyser

Overview
Calculates total annual usage and average monthly usage from monthly usage values.

Concepts Practiced
- Variables and numeric data
- Arithmetic operations
- Console output and formatting

File
`MonthlyUsageAnalyser.java`

Run
```powershell
javac MonthlyUsageAnalyser.java
java MonthlyUsageAnalyser
```
If the file declares a package, compile and run it from the correct source root using its fully qualified class name.

Expected Result
Displays total annual usage and average monthly usage based on the values provided in the program.

Status
Completed as part of the HCL Java daily tasks.
