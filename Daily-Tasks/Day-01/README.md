Day 01 – Java Platform Information

Overview
A Java program that displays information about the Java runtime and operating system.

Concepts Practiced
- Running a Java program
- `System.getProperty()`
- Console output and basic compilation

File
`PlatformInfo.java`

Run
```powershell
javac PlatformInfo.java
java PlatformInfo
```
If the file declares a package, compile and run it from the correct source root using its fully qualified class name.

Expected Result
Displays details such as Java version, operating system name, and architecture.

Status
Completed as part of the HCL Java daily tasks.
