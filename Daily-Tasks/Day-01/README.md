 Day 1 – HCL Daily Task

 1. Java

 Topics Covered

* Introduction to Java
* JDK, JRE, and JVM
* JVM Architecture
* Java Compilation and Execution Flow
* Java Bytecode

 Key Learnings

* JDK (Java Development Kit): Used to develop Java applications.
* JRE (Java Runtime Environment): Provides the environment required to run Java applications.
* JVM (Java Virtual Machine): Executes Java bytecode.
* Java source code is written in a `.java` file.
* The `javac` compiler converts Java source code into bytecode stored in a `.class` file.
* The JVM loads and executes the bytecode.

 Compilation and Execution

Java Source Code (.java)
        ↓
      javac
        ↓
Bytecode (.class)
        ↓
       JVM
        ↓
    Execution

 Commands Practiced

javac PlatformInfo.java
java PlatformInfo
javap -c PlatformInfo
java -verbose:class PlatformInfo

 2. Agile / Scrum

 Topics Covered

* Agile methodology
* Scrum framework
* Sprints
* Daily Stand-ups
* Sprint Retrospectives
* User Stories
* Estimation and Story Points
* Definition of Done

 Key Learnings

* Sprint: A fixed period during which the Scrum team works on selected tasks.
* Daily Stand-up: A short daily meeting to discuss progress, planned work, and blockers.
* Sprint Retrospective: A meeting to discuss what went well, what did not go well, and what can be improved.
* User Story: Describes a requirement from the user's perspective.
* Story Points: Used to estimate the relative effort and complexity of a task.
* Definition of Done: A set of conditions that must be satisfied for a task or user story to be considered complete.
